# English Localization

This build is the English-localized edition of `moba_map_viewer_v0_8`.

Localized areas include the main interface, editor, mesh workflow, visualization controls, strategic topology/object controls, runtime validation and status messages, mesh/object-type errors, and bundled documentation.

Internal IDs, map-object type IDs, JSON field names, renderer IDs, and JavaScript APIs are unchanged for compatibility.
